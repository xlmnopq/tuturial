# 教师使用说明

## 课程组织

全套材料共 9 个 Notebook，可按课时选用，未要求每个学生跑遍所有模型。

| 单元 | 建议课堂内容 | 课后任务 |
|---|---|---|
| 环境与完整分类流程 | 00 环境、01 CIFAR-10 基线，理解 train/val/test | 学习率与增广对照实验 |
| 现代卷积网络 | 分组运行 02 AlexNet、03 VGG11、04 ResNet18 | 交换结果，做同划分比较 |
| 文本分类 | 05 IMDB 分词、词表和 BiLSTM | 06 TextCNN，与 BiLSTM 比较 |
| 生成模型 | 07 VAE 重构与先验生成、08 GAN 交替训练 | 比较潜维度、KL 权重或 G/D 学习率 |

无需在课堂等待每个模型完全训练。教师先验证环境，课堂先执行 smoke，正式模型可在课后服务器训练。

## 课前准备

1. 统一 Python 环境，执行 `check_environment.py`，核对实际解释器和 GPU。
2. 执行 `python prepare_data.py --dataset all`。CIFAR-10 源较慢时用 `--cifar-mirror`，数据仍验证官方 MD5。
3. 将数据缓存放在共享磁盘，或复制到学生项目中的 `data/`。IMDB 无标签数据不会用于实验。
4. 运行 `python tools/smoke_all.py` 检查分类与文本全部入口。生成模型的检查命令见 `GENERATIVE_GUIDE.md`。
5. 选择学生负责的模型，统一正式训练预算、验证协议与结果目录命名。

## 演示时的观察点

- DataLoader 的图像批次 `[B,3,H,W]` 与文本批次 `[B,L]`，标签均为 `long`。
- 图像验证和测试无随机增广。分类图像使用固定归一化，原生 ImageNet 扩展使用对应归一化。
- `model.train()` 与 `model.eval()` 对 Dropout、BatchNorm 的影响。
- 训练时执行 `zero_grad → forward → loss → backward → step`，评估时不更新参数。
- 指标按样本累计，不对大小不同的 batch 简单平均。
- 模型移到 GPU 后再创建优化器，保存 `state_dict`，预测时恢复同一配置与预处理。
- IMDB 词表只统计训练数据，未知词与填充词含义不同，真实长度不能用填充后的长度替代。
- VAE 重构评价与先验生成质量不同，GAN 的 D loss 不能为 G 的图像质量排序。

## 建议评分

| 内容 | 分值 |
|---|---:|
| 跑通数据、训练、测试和独立恢复预测 | 30 |
| 正确处理划分、预处理、词表与随机种子 | 20 |
| 控制变量实验与完整记录 | 25 |
| 分析错例、局限和失败情况 | 15 |
| 代码可读性与报告可复现性 | 10 |

评分看流程正确性、证据和分析，不以单次最高测试准确率为唯一依据。测试集反复用于调参应在报告中说明，并重新考虑有效的最终评价。

## 可选的分层任务

- 基础：使用默认结构，能解释数据维度、损失和测试结果。
- 进阶：替换分类头、修改 Dropout、处理文本 PAD、调整潜维度。
- 扩展：调用 torchvision 预训练模型，明确额外预训练来源；设计生成模型的语义质量评估方案。

不要求学生安装 `d2l`、`torchtext`、预训练词向量或额外 NLP 数据集。当前包没有分布式训练和断点续训入口，已有模型的运行目录会拒绝覆盖；增加训练预算时使用新的目录。
